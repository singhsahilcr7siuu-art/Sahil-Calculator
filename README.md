# Calculator

A clean, simple calculator that performs basic arithmetic operations right in your browser.

##  Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear (C) and delete (⌫) buttons
- Responsive design that works on desktop and mobile
- Keyboard support

##  Demo

[Live Demo](https://your-username.github.io/calculator/)

##  Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/calculator.git
   ```
2. Navigate into the project folder:
   ```bash
   cd calculator
   ```
3. Open `index.html` in your browser.

No dependencies or build steps required.

##  Usage

1. Click the number buttons or use your keyboard to enter numbers.
2. Choose an operator (`+`, `-`, `×`, `÷`).
3. Press `=` or `Enter` to see the result.
4. Press `C` or `Esc` to clear.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Enter digits |
| `+ - * /` | Operators |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last digit |
| `Esc` | Clear all |
